# bff.runtimeFramework

- **类型：** `'hono' | 'effect'`
- **默认值：** `'effect'`

import EnableBFFCaution from "@site-docs/components/enable-bff-caution";

<EnableBFFCaution />

用于控制 Modern.js BFF 路由使用的运行时框架。

```ts title="modern.config.ts"
export default defineConfig({
  bff: {
    runtimeFramework: 'effect',
  },
});
```

- 设置为 `'effect'` 时，仅从 `api/effect/index` 运行 BFF（Effect HttpApi 运行时）。
- 设置为 `'hono'` 时，仅从 `api/lambda/**` 的文件约定处理函数运行 BFF。

两种运行时之间没有隐式回退，应用需要显式选择其一。
如果需要优先使用 Effect 分支的公开 UltraModern 预设，请在应用中显式设置，或使用 create 模板提供的 Effect 脚手架路径。

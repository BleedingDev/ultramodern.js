### pnpm

It is recommended to use [pnpm](https://pnpm.io/installation) to manage dependencies:

```bash
corepack enable pnpm
corepack prepare pnpm@11.1.2 --activate
```

:::note
Modern.js also supports dependency management with `yarn` and `npm`.

:::
